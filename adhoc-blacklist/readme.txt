For each derived-once net that is either ruled out or shown to be realizable in an ad-hoc way, a subdirectory should be created in adhoc-whitelist or adhoc-blacklist.
The subdirectory should be named as the id of the derived-once net.

The content of the subdirectory will not be processed by any software.
Inside the subdirectory there should be some "proof" or "description" of the ad-hoc argument that is needed to take care of the net.
