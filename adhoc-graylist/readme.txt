This directory, adhoc-graylist, contais subdirectories identified by the number of a net. The corresponding net falls in the following two categories.
a) It can be obtained by removing edges from a Heppes net, but the result would not be an admissible once-derived net (the admissible ones are whitelisted). It has however not yet been decided whether the net should be discarded or could be whitelisted.
b) The net can be reduced to a) by triangle elimination.

The content of the subdirectory will not be processed by any software.
Inside the subdirectory there should be:
- A description of how it can be obtained from a Heppes net, if it is in category a).
- To which net in category a) it reduces once eliminating all the triangles, if it is in category b).
